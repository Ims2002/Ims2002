### 🚀 Proyectos destacados

> 🌐 **[Pet Hotel](https://pethotelp9.com)** — Plataforma web en producción para un hotel canino. Reservas, e-commerce con Stripe, panel admin, predicción de raza con IA y sistema de afiliados con Amazon.
> `Laravel 12` · `Filament` · `Livewire` · `Stripe` · `Tailwind`

> 🎬 **Filmer** — Aplicación de gestión de películas y actualidad cinematográfica integrada con la API de TMDb.
> `Laravel` · `TMDb API`

> 🐕 **K9Scanner AI** — Microservicio de clasificación de razas caninas a partir de imágenes, usando un modelo de Hugging Face.
> `FastAPI` · `Hugging Face` · `Docker`

> 📊 **[Análisis de Ventas BMW](https://github.com/Ims2002/analisis_ventas_bmw)** — Análisis completo de 14 años de ventas mundiales de BMW (2010-2024) con dashboard interactivo e insights de negocio accionables.
> `Excel` · `Power BI` · `Data Analysis`

> 🦠 **[Proyecto COVID](https://github.com/Ims2002/Proyecto-Final-COVID)** — Pipeline de datos que unifica múltiples datasets de Our World in Data en un único dataset semanal listo para EDA.
> `Python` · `pandas`

> 👁️ **[CVProjects](https://github.com/Ims2002/CVProjects)** — Pong y Snake controlados con la webcam usando detección de manos en tiempo real.
> `Python` · `OpenCV` · `Pygame` · `Mediapipe`

🔎 Y mucho más en mis **[repositorios](https://github.com/Ims2002?tab=repositories)** — sigue explorando.
